# Medical Digital Twin for Personalized Treatment Recommendation

## Overview
Medical Digital Twin is an AI-powered healthcare system that creates a virtual representation of a patient using Electronic Health Records (EHR), physiological parameters, and real-time sensor data.

## Objectives
- Real-time patient monitoring
- Disease risk prediction
- Personalized treatment recommendation
- Explainable AI using SHAP and LIME
- Healthcare decision support

## Technologies
- Python
- Scikit-learn
- TensorFlow
- XGBoost
- Flask / FastAPI
- HTML, CSS, JavaScript, Bootstrap
- MongoDB / SQLite
- SHAP
- LIME
